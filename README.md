# PM Relief Registration Scheme (C++ Console Application)

A first-semester C++ console simulation that verifies applicant eligibility and calculates monthly relief amounts based on vehicle category and registration rules.

## Features
- 13-digit CNIC length validation and gender-based applicant tracking
- Vehicle category selection (Motorcycle, Qingqi, Rickshaw, Car)
- Eligibility checks for vehicle registration year (2006 or newer), car engine capacity (up to 800cc), and registered ownership
- Automated approval/rejection decisions and monthly relief calculation (Rs. 2000 / Rs. 3000)
- Summary report displaying total applicants, male/female counts, total relief distributed, and acceptance rate

## C++ Concepts Used
- Conditional statements and nested `if-else` logic
- `while` and `do-while` loops
- Counters, arithmetic operators, and `iomanip` formatting

*Note: This is an academic C++ project built for learning programming fundamentals and is not affiliated with any government service.*
